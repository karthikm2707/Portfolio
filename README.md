# Portfolio - Karthik M

Personal Portfolio website for **Karthik M**, B.E. Mechatronics Engineering student and Industrial Automation & Robotics aspirant.

## 🚀 Features
- **Modern Responsive Design**: Built with smooth glassmorphism UI, gradient accents, and mobile-friendly responsive layout.
- **Interactive Project Tabs**: Switch dynamically between Major Projects and Mini Projects.
- **Comprehensive Overview**: Details experience, educational qualifications, CSWA certification, skills, achievements, and contact information.

## 🛠️ Built With
- HTML5
- CSS3 (Vanilla CSS with CSS variables, Glassmorphism design system)
- FontAwesome Icons
- JavaScript (DOM Tab Switcher)

## 📌 Sections
1. **Hero / About**: Contact pills, career objective, and quick intro.
2. **Education**: Academic journey and CGPA/percentages.
3. **Skills**: Technical capabilities, certifications (CSWA), and key areas of interest.
4. **Projects**: Interactive showcase of Mechatronics & Automation projects.
5. **Achievements & Activities**: Awards, paper/project presentations, and workshops.
